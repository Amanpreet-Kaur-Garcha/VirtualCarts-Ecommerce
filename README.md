# VirtualCarts – Modern E-Commerce Frontend Website

VirtualCarts is a modern responsive e-commerce frontend website developed using HTML5 and CSS3. The project focuses on creating a clean and visually appealing online shopping experience with organized product categories, modern layouts, responsive design, and interactive UI components.

The website includes multiple product category pages, authentication pages, a shopping cart interface, mega menu navigation, and responsive layouts for desktop, tablet, and mobile devices.

# Features
- Modern responsive e-commerce UI
- Sticky navigation header
- Mega menu category navigation
- Fashion, Electronics, and Travel product pages
- Product card layouts
- Login page
- Signup page
- Shopping cart page
- Hover animations and transitions
- Responsive mobile layouts
- Clean modern typography

# Technologies Used
- HTML5
- CSS3
- Font Awesome
- Google Fonts
- Flexbox
- CSS Grid
- Media Queries
